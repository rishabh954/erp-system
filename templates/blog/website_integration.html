    How It Works
    1. Employee creates and submits blog post for approval.
    2. Manager approves the post.
    3. Authorised user clicks Publish.
    4. ERP sends post data to your website via the configured API endpoint.
    5. Website confirms publication and returns the public URL.
    6. ERP stores the URL and marks the post as Published.

    Idempotency: Each publish request includes a unique key so retries never create duplicate articles.
