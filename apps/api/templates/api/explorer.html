Quick Start: Get a Token
# Python Example
import requests

response = requests.post(
    'http://localhost:8000/api/auth/token/',
    json={
        'username': 'your_username',
        'password': 'your_password'
    }
)
token = response.json()['access']

# Use the token in subsequent requests
headers = {'Authorization': f'Bearer {token}'}
products = requests.get(
    'http://localhost:8000/api/inventory/products/',
    headers=headers
).json()
Filtering & Search
# Filter by field value
GET /api/sales/orders/?status=confirmed

# Full-text search
GET /api/inventory/products/?search=laptop

# Ordering (prefix - for descending)
GET /api/crm/customers/?ordering=-created_at

# Pagination
GET /api/sales/orders/?page=2&page_size=10

# Combine filters
GET /api/sales/invoices/?status=overdue&ordering=-due_date
cURL Example
# Step 1: Obtain a token
curl -X POST http://localhost:8000/api/auth/token/ \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"pass"}'

# Step 2: Call an endpoint
curl http://localhost:8000/api/inventory/products/ \
  -H "Authorization: Bearer <your_token>"
